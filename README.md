# 🥷 Phrase Ninja 🍉

Jeu pour enfants inspiré de Fruit Ninja : tranche les phrases demandées, laisse tomber les autres.
Révision des types de phrases (déclarative, interrogative, exclamative, impérative) et des formes
(affirmative/négative, active/passive, neutre/emphatique, personnelle/impersonnelle).

**Jouer :** https://arnaudcasella2025.github.io/PhraseNinja/

- ⚙️ Paramètres : cocher les types et formes à réviser, vitesse.
- Modes Classique (3 vies) et Chrono (90 s).
- Bilan de fin de partie avec les phrases à revoir.

Un seul fichier `index.html`, sans dépendance.
